A one-line roast for the [Midnight Fridge Roast](https://make.fun/bounty/u-carbon-forge-midnight-fridge-roast-fc5d44a7) bounty on make.fun. The program writes a single roast line — a smart fridge that locks itself at midnight and treats the leftovers like VIPs — to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

> My fridge locks itself at midnight like a bouncer, and apparently the leftovers are VIPs and I'm not on the list.

## Run

```sh
node main.ts
```

Requires Node 22.18+ (or 22.6+ with `--experimental-strip-types`). The output directory defaults to `/output`; set `MAKEFUN_OUTPUT_DIR` to change it.
